# 00 · Glossary

Short definitions for the paper docs. The wording here is the public English. Parameters that are still unset are listed in [OPEN-ITEMS.md](./OPEN-ITEMS.md).

| Term | Meaning |
|------|---------|
| **TCA** | Trading Cards Assets. The prototype launchpad, and in this draft the platform token. Slogan: **Make TCG more fun.** |
| **Positioning** | The on-chain asset-tokenization and themed-issuance platform for graded physical cards. |
| **Platform token (TCA)** | The launchpad’s own token. A treasury buyback of platform TCA buys this token. A TCA trade burns TCA. Total fee: **10%** until about **$1M** cumulative volume, then **5%** until about **$10M**, then **2.5%**. |
| **Theme token** | The token for one theme slot. It is distinct from platform TCA. A theme-token trade burns that theme token. Total fee: fixed **2.5%**. |
| **Theme slot** | One theme, one slot, one theme token. Example names are illustrative only. A name marks a slot. It does not mean a card is in custody or that a token has been issued. |
| **Graded card** | A professionally graded physical trading card of the theme. These docs say “graded cards.” |
| **Hard cap** | The card-pledge ceiling, about **$1,000**, first come, first served. A pledge above the cap is returned. |
| **Soft cap** | The token-sale ceiling, about **$100,000**. While the sale fills, buy protection sets the instantly sellable share. When the soft cap is reached, the token launches and can trade, and that rule lapses. |
| **Pledge** | Graded cards of a theme put toward the hard cap to earn issuance rights. |
| **Pledger** | A person who pledges graded cards of a theme. A pledger is not necessarily the controller of the theme token. |
| **Staker share** | The **20%** fee bucket paid to pledgers whose pledges counted toward the hard cap. |
| **Treasury** | The **40%** fee bucket. The platform executes it by the rules: buy graded cards of that theme, and buy back platform TCA. The split between those two uses is not set. |
| **Platform (fee bucket)** | The **20%** fee bucket that stays with the platform to run the launchpad. Separate from the about 10–30% of a new pledge pool the platform may join. |
| **Buyback & burn** | The **20%** fee bucket. Buy back and burn the token of that trade (TCA trades burn TCA; theme-token trades burn that theme token). |
| **SBT** | Soulbound token. Non-transferable. Lottery eligibility, as a direction, asks for at least **10** Renaiss SBTs. |
| **Partner** | The public word for the Renaiss relationship. Invite: https://www.renaiss.xyz/ref/tcahub |
| **Council** | The 12-seat body that confirms decisions: buybacks, burns, which theme launches next, and how treasury funds are used. Seats are screened from the community and added only after human review. A theme token may also have its own community council. |

Fee buckets are in [03-fees-treasury.md](./03-fees-treasury.md). The seven steps are in [02-mechanism.md](./02-mechanism.md). The Council is in [06-council.md](./06-council.md).
