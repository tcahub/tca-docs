# 00 · Glossary

Short definitions for the paper docs. The wording here is the public English, following the V4 paper. Straight apostrophes are used throughout. Parameters that are still unset are listed in [OPEN-ITEMS.md](./OPEN-ITEMS.md).

| Term | Meaning |
|------|---------|
| **TCA** | Trading Cards Assets. The launchpad, and in this draft the platform token the treasury can buy back. Slogan: **Make TCG more fun.** |
| **What TCA is** | A launchpad that brings graded physical cards on-chain: each card theme becomes one slot, and each slot issues one token — asset tokenization, issued by theme. |
| **Theme token** | The one token for one theme slot. Total fee: a flat **2.5%**. Fixed supply in the working proposal: 1,000,000,000. |
| **Theme slot** | One theme, one slot, one token. Example names are illustrative only. A name marks a slot. It does not mean a card is in custody or that a token has been issued. |
| **Graded card** | A professionally graded physical trading card. These docs say "graded cards." Cards stay forever. |
| **Hard cap** | The card-pledge ceiling, about **$1,000** per theme, and **$200** per wallet. A theme opens only with at least **5** counted pledgers. A card worth more than $200 still counts as $200. |
| **Soft cap** | The token-sale ceiling, about **$100,000**. Once filled, the token launches and trades freely. Quota release lapses at that moment. |
| **Pledge** | Graded cards of a theme, and in part TCA, put toward the hard cap. At least half of the counted value must be cards. Pledging is whitelisted through X. |
| **Pledger** | A person whose pledge counts toward the cap. Pledgers are the founding community. They are not necessarily the controllers of the theme token. |
| **Staker share** | The **20%** fee bucket. It goes to pledgers whose pledges counted toward the cap. For theme tokens this share belongs to that theme's pledgers. The seven-step line calls this same bucket **20% pledgers**. |
| **5% pledgers** | A supply allocation, not the fee bucket. About 5% of the theme-token supply, split equally by counted pledgers and unlocked daily over 30 days. The card itself is a refundable pledge. This 5% is the reward, not the compensation. |
| **Treasury** | The **40%** fee bucket. The platform buys graded cards of that theme on Renaiss and buys back platform TCA. Purchases and offers are disclosed on a regular basis. |
| **Platform (fee bucket)** | The **20%** fee bucket that stays with the platform to run the launchpad. |
| **Buyback & burn** | The **20%** fee bucket. Buys back and burns the token of that trade. Supply only shrinks. |
| **Quota release** | During filling, two tracks run in parallel. Whichever track triggers first sets the instantly released share at 10%, 20%, or 30%, and once set it does not switch. The rest releases daily over **21 days**. |
| **CBR** | Card Backing Ratio. Card FMV in the theme treasury ÷ theme market cap. A disclosure metric. Not a price floor and not a redemption right. |
| **SBT** | Soulbound token. Non-transferable. Lottery eligibility, as a direction, asks for at least **10** Renaiss SBTs. |
| **Partner** | The public word for the Renaiss relationship. Invite: https://www.renaiss.xyz/ref/tcahub |
| **Council** | The 12-seat body that decides which IP launches next, how treasury funds are spent, and how fees and rules evolve. Seats are screened from the community. A theme token may also have its own community council. |

Fee buckets are in [03-fees-treasury.md](./03-fees-treasury.md). The seven steps are in [02-mechanism.md](./02-mechanism.md). Supply, backing, and liquidity are in [08-supply-backing-liquidity.md](./08-supply-backing-liquidity.md).
