# 00 · Glossary

Short definitions for the paper docs. The wording here is the public English. Parameters that are still unset are listed in [OPEN-ITEMS.md](./OPEN-ITEMS.md).

| Term | Meaning |
|------|---------|
| **TCA** | Trading Cards Assets. The prototype launchpad for trading-card themes, and the name of the platform token. |
| **Platform token (TCA)** | The launchpad’s own token. A treasury buyback of platform TCA buys this token. A TCA trade burns TCA. |
| **Theme token** | The token for one theme slot. It is distinct from platform TCA. A theme-token trade burns that theme token. |
| **Theme slot** | One theme, one slot, one theme token. Each theme occupies a single slot. |
| **Graded card** | A professionally graded trading card of the theme. These docs say “graded cards.” |
| **Hard cap** | The stake-pool ceiling, about **$1,000**, first come, first served. Stake above the cap is returned. |
| **Soft cap** | The raise ceiling used for buy protection, about **$100,000**. |
| **Staker** | A person who stakes graded cards of a theme. A staker is not necessarily the controller of the theme token. |
| **Staker share** | The **20%** fee bucket paid to staking participants whose stake counted toward the hard cap. |
| **Treasury** | The **40%** fee bucket. The platform carries it out under the rules: buy graded cards of that theme, and buy back platform TCA. The split between those two uses is not set. |
| **Platform (fee bucket)** | The **20%** fee bucket that stays with the platform to run the launchpad. Separate from the about 10–30% of a new stake pool the platform may join. |
| **Buyback & burn** | The **20%** fee bucket. Buy back and burn the token of that trade (TCA trades burn TCA; theme-token trades burn that theme token). |
| **SBT** | Soulbound token. Non-transferable. Lottery eligibility, as a direction, asks for at least **10** Renaiss SBTs. |
| **Partner** | The public word for the Renaiss relationship. |
| **DAO** | The body that confirms decisions: buybacks, burns, and which theme or series to support. Tentatively 12 community-sourced seats, added only after human review. |

Fee buckets are in [03-fees-treasury.md](./03-fees-treasury.md). The seven steps are in [02-mechanism.md](./02-mechanism.md).
