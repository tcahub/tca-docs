# 01 · Position

**One line:** Make TCG more fun.

**Positioning.** The on-chain asset-tokenization and themed-issuance platform for graded physical cards.

**What TCA is.** TCA is a launchpad that brings graded physical cards on-chain: each card theme becomes one slot, and each slot issues one token.

One theme, one slot, one token. Pikachu, Charizard, and Gengar are example slots. Eevee, Rayquaza, Luffy (One Piece), and a Naruto series are queued examples. These names are illustrative only. A name marks a slot. It does not mean a card is in custody or that a token has been issued. No theme is tradable yet. The launchpad frame is a prototype, and the slots are not live.

This stage is paper. This page does not connect a wallet, does not buy or sell, and does not run a lottery.
